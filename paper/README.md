# Paper

The manuscript is [`main.tex`](main.tex); the compiled version is
[`main.pdf`](main.pdf). [`arxiv_submission.zip`](arxiv_submission.zip) contains
the manuscript, its three figure assets and `orcidlink.sty` for source submission.

The slender body is the main simulation and station-keeping case. The compact
body is retained as the verification-ladder reference and geometry comparison;
both use the same 4.7 mm acceleration gap. The mission model uses a 30 mm
approximation of the 30.5 mm slender PIC body and its own collection calibration.

Build from this directory:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

## Figures and provenance

| Figure | Asset | Source |
|---|---|---|
| Operating sequence | `imgs/concept_steps_mpl.pdf` | Concept schematic, generated by `figs/make_device_figs.py` |
| Simulated geometry | `imgs/device_geometry.pdf` | Frozen compact and slender reference configurations; uses the slender README's isometric drawing primitives |
| Four-panel PIC results | `imgs/dashboard_slender_200v.png` | Slender run `20260806T011847Z_5670e54c`, also shown in the main README GIF |

From the repository root, in the `warpx-cpu-mpich-dev` environment:

```bash
python paper/figs/make_submission_figs.py
```

The geometry can be reproduced from committed files with `--geometry-only`.
The dashboard requires the run's local `outputs/` directory, including its
openPMD field dumps and `contactor_log.csv`. The density panel uses the final
field dump; the time histories use the simulation ledger. Beam-supply power is
`abs(phi_body - V_cathode) * I` during emission and zero before beam turn-on.
This differs from cathode-to-plasma voltage times current.

To reproduce the main README animation, use the capstone renderer because the
archived slender run retains its original `capstone.floating_body` stage ID:

```bash
python pic_sims/ladder/capstone/2_chipsat_thruster/viz/animate_dashboard.py \
  --run pic_sims/characterization/slender_body/outputs/20260806T011847Z_5670e54c \
  --out /tmp/thruster-slender-200v.mp4 \
  --title 'Slender electron thruster (200 V)' --fps 10
ffmpeg -y -i /tmp/thruster-slender-200v.mp4 \
  -filter_complex '[0:v]fps=10,scale=1400:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse' \
  paper/imgs/dashboard_200v.gif
```

The older `imgs/dashboard_200v.png` is the compact-body run
`20260805T045954Z_b87fbefc`; it is not the paper's slender-body figure.
No cathode-launch correction has been applied to the reported performance.
